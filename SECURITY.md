## 💡 Pro Tips

- **Disable Office Auto-Update** — Office updates sometimes break Project activation. Set `File → Account → Update Options → Disable Updates` and manually check compatibility before updating.
- **Backup License Registry Key** — The activator stores KMS activation in `HKLM\SOFTWARE\Microsoft\Office\ClickToRun\Configuration`. Export this registry key to restore Professional status after reinstalls.
- **Use Power BI for Dashboards** — Project Professional includes Power BI Desktop connector. Export project data to Power BI for executive dashboards instead of basic Excel reports.
- **Test Offline Mode First** — After activating, disconnect internet and restart Project. If Professional features work offline, activation is permanent. If it reverts to trial, re-run activator.
- **Share .mpp Files, Not .mpt** — Professional users can open .mpp project files in Standard (view-only). Use .mpp format for client deliverables to avoid "requires Professional" errors.
